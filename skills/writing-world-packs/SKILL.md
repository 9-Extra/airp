# 编写 AIRP 世界包

世界包就是一个 skill：GM（AIRP 预设的 AI）开局时用 skill 工具加载 SKILL.md 全文，把它当作裁决的唯一规则依据；细节文件由 GM 之后用 read_file 按需阅读。

世界包不碰代码：它告诉 GM 要追踪什么状态、如何计算，GM 自行用 world_run 写代码完成初始化、判定与更新。所以规则可以用自然语言、伪代码或代码片段写，写到可计算的程度即可；模糊描述会得到 GM 的灵活裁量（合适时可以用）。

## 信息量预算

- **SKILL.md 必然被完整读取**：放每个回合都可能用到的东西——基调、状态清单、核心判定规则、索引。写完逐段自问："这一段是不是几乎每个回合都用得上？"不是就拆出去。
- **references/*.md 按需读取**：一切有触发条件的内容（物品表、法术列表、地点详情、特殊分支、秘密）都该放这里。
- 写作就是在两个区域之间分配内容：常用度越高越靠 SKILL.md，触发条件越具体越该拆出去。。

## 不遗漏：靠索引和 normalize，不靠 GM 的记忆

GM 漏用规则的原因几乎从来不是"没写"，而是"不知道它存在"或"忘了现在该查"。两道保险：

1. **完整索引（防"找不到"）**：SKILL.md 末尾必须有一张表，覆盖全部拆分文件，格式为 `触发时机 → 文件 → 一句话内容预告`。索引只指路、不装内容。遗漏的根源是索引没告诉 GM "存在这个文件、什么时候读它"，而不是文件不存在。GM没有枚举文件（ls）能力，因此非SKILL.md的文档都必须有索引，否则GM找不到。
2. **触发器表（防"忘了查"）**：把"当 X 时自动 Y / 提醒 Z"集中成一张清单（如"hp ≤ 上限25% 时提醒濒死状态""每日黎明结算补给消耗"）。GM 开局会把它翻译成 world_run 的 normalize 整理函数（每次执行后自动调用一次），此后由代码保证触发，不再依赖上下文记忆。条件式规则尽量收成这张表，而不是散在各章节里。

## 定位效率：按触发场景拆分，而非按设定类别

- **一个场景一个文件**：按"GM 什么时候需要它"分（战斗.md、社交.md、旅行.md、交易.md、升级.md……），不按设定类别分（地理.md、历史.md）。GM 一次查找只读一个文件，读到的全是当前场景的有效信息。
- **每个文件自包含**：只读它一个就足以裁决对应场景。共享概念（术语表、通用公式、通用物价）收进 `references/glossary.md`，索引里标注"前置阅读"。
- **同一规则只定义一处**，其他地方用指针。重复既费 token，又在改动时制造不一致。
- **命名用玩家会说的词**：GM 是靠玩家输入的关键词匹配文件的；文件名和小标题要跟玩家用语对齐。超过百行的文件开头放目录。表格优于段落。

## 秘密与剧透隔离

未揭示的真相、隐藏支线、反派的真实动机等单独成文件，索引中标注"仅当 X 发生后阅读"。AI 读过的内容会渗进叙事；没读过就不会剧透——按需隔离既省 token，也是防剧透机制。

## SKILL.md 必备章节

```markdown
---
name: dark-forest
description: 幽暗森林：低魔奇幻求生世界。（写清世界名与一句话基调——玩家说"开始《幽暗森林》"时 GM 靠它匹配）
---

# 世界观
（基调、常识、势力轮廓——叙事依据，只写每个回合都可能影响演绎的部分。）

# 状态清单
（GM 照此在 world_run 初始化 state 的标准。每字段写清：名称、初始值、取值范围/单位、更新时机。例：）
- 生命值 hp：初始 50，0–50，受伤/治疗时更新
- 体力 sp：初始 30，0–30，冲刺/战斗消耗，每休息 1 小时恢复 10
- 金币、物品栏（含重量；负重上限 = 力量 × 5）
- 当前位置与游戏内时间（回合制，1 回合 = 10 分钟）

# 判定规则
（核心判定写到可计算的程度：公式、骰子表达式、阈值表。例：潜行判定 = d20 + 敏捷修正 ≥ 目标警觉值。冷门判定拆到 references。）

# 触发器表
（"条件 → 效果/提醒"清单，GM 开局翻译成 normalize 整理函数。例：hp ≤ 12 → 提醒"濒死：全判定 -2"。）

# 开局
（初始场景、初始资源、开场氛围。多开局或复杂开局拆 references/openings/*.md。）

# 索引
| 触发时机 | 文件 | 内容 |
| 进入战斗 | references/combat.md | 先攻、攻击/伤害公式、状态异常 |
| 与 NPC 交涉 | references/social.md | 好感度判定与价目 |
| 玩家问及背景设定 | references/glossary.md | 术语与年表（前置阅读） |
| 玩家发现密室 | references/secrets.md | 仅当密室被发现后阅读 |
```

## 交付前自检

- 随便想 5 个玩家可能的行为，每个都能在索引里一步找到入口？
- 随机抽一个 reference 文件，只读它一个就够裁决对应场景？
- 同一规则是否只定义了一处？
- 所有条件式规则是否都收进了触发器表？
- 所有剧透内容是否都标了"仅当 X 后阅读"？
- 逐段检查 SKILL.md：有没有哪段不是每个回合都用得上？有就拆出去。
